# EVA — Intelligent Rule-Based Assistant

> A lightweight, interactive chatbot built with Python and Tkinter, designed around structured rules and a simple conversational experience.

## About EVA

EVA is a desktop-based rule-driven chatbot created to explore the foundations of conversational systems through practical programming and interface design.

Instead of relying on complex machine-learning models, EVA uses predefined rules and logical conditions to interpret user input and provide relevant responses. This approach keeps the system lightweight, predictable, and easy to understand while still creating an engaging conversational experience.

EVA was developed as a practical project during my **AI Internship at DecodeLabs in 2026**.

## ⚙️ How EVA Works

EVA follows a straightforward conversational flow:

**User Input → Input Processing → Rule Matching → Response Selection → EVA Response**

When a user enters a message, EVA evaluates it against its predefined rules and identifies the most appropriate response. The selected response is then displayed through the graphical interface.

Because the system is deterministic, its behavior is transparent and its responses can be easily tested and refined.

## Getting Started

### Prerequisites

Make sure **Python 3.x** is installed on your system.

Tkinter is included with most standard Python installations.

### Run EVA

Clone the repository:

```bash
git clone https://github.com/FaizaEsha/EVA-rule-based-chatbot.git
```

Navigate to the project directory:

```bash
cd eva-rule-based-chatbot
```

Run the chatbot:

```bash
python evabot.py
```

The EVA desktop interface should launch locally.
